Sistema de Cálculo de Impostos

Aplicação desenvolvida em Java para praticar os conceitos de Programação Orientada a Objetos (POO), utilizando herança, polimorfismo e classes abstratas.

O programa lê os dados de contribuintes informados pelo usuário, podendo ser pessoas físicas ou jurídicas, e calcula o imposto devido de acordo com regras específicas para cada tipo de contribuinte. Ao final, o sistema exibe o imposto pago individualmente e o total arrecadado.

Regras de negócio
Pessoa Física
Renda abaixo de 20.000: imposto de 15%
Renda igual ou acima de 20.000: imposto de 25%
Gastos com saúde geram abatimento de 50% no imposto
Pessoa Jurídica
Empresas pagam 16% de imposto
Empresas com mais de 10 funcionários pagam 14%
Conceitos aplicados
Herança
Polimorfismo
Classes abstratas
Encapsulamento
Sobrescrita de métodos
Coleções com ArrayList
Entrada de dados com Scanner
Tecnologias utilizadas
Java
Programação Orientada a Objetos (POO)
Objetivo

Praticar modelagem de classes e aplicar os pilares da orientação a objetos na criação de um sistema simples de cálculo de impostos.
